# دليل التحويل عبر إنستاباي — شركة الوسام

تطبيق تعليمي للجوال يشرح لعملاء شركة الوسام كيفية التحويل عبر تطبيق إنستاباي إلى:
- حساب بنك مصر
- حساب CIB
- محفظة فودافون كاش

## التشغيل

```bash
npm install
npm run dev
```

افتح [http://localhost:3000](http://localhost:3000) من الموبايل أو من وضع الموبايل في المتصفح.

## التقنيات

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- واجهة عربية RTL محسّنة للجوال
